## Formatacao e obtenção de dados pluviométricos Hidroweb

Este projeto tem como objetivo:

    1. Obter dados pluviométricos de uma sub-bacia específica do estado de Pernambuco através do Hidroweb (Sistema da ANA - Agência Nacional de Águas).

    2. Formatar os dados temporais em duas colunas estruturadas:

    - Data (timestamps)

    - Chuva (mm) (valores de precipitação).


## Funcionalidades

Pré-processamento de dados:

- limpeza

- formatação

- filtragem




## Exemplo de saída

| Data       | Chuva (mm) |  
|------------|------------|  
| 2023-01-01 | 12.5       |
